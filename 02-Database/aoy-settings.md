# ค่าตั้งค่าของร้านตัวอย่าง AOY

กลับไป [[00-Index]] · ความหมายตัวเลือก [[company-options]] · GL [[pricing-vat-gl]] · รหัส GL [[gl-action-codes]]

> อ่านเฉพาะตารางตั้งค่า (`erp_option`, `erp_doc_format`, `erp_doc_format_gl`) — ไม่มีข้อมูลลูกค้า ไม่ได้อ่านคอลัมน์ token/รหัสผ่าน

## ตัวเลือกที่เปลี่ยนพฤติกรรม (`erp_option`)
| ตัวเลือก | ค่า AOY | ผล |
|---|---|---|
| `gl_process_realtime` | 0 | **ไม่ลง GL ทันทีหลังบันทึก** → GL สร้างจากเมนูประมวลผลเป็นชุด (สอดคล้องกับที่ gl_journal มีน้อยกว่าเอกสาร) |
| `inventory_gl_post` | 1 | ระบบสินค้าแบบ **Perpetual** (ลงต้นทุนขาย/สินค้าคงเหลือรายเอกสาร, ใช้ action 101/103) |
| `disable_ic_cost_process` | 0 | คำนวณต้นทุนหลังบันทึกทุกครั้ง |
| `vat_rate` | 7.00 | อัตรา VAT |
| `multi_currency` | 0 | สกุลเงินเดียว |
| `item_amount/price/qty_decimal` | 2 / 2 / 2 | ทศนิยม |
| `gen_doc_no_auto` | 1 | รันเลขที่เอกสารอัตโนมัติ |
| `select_branch_first` | 1 | ให้เลือกสาขาตอนเข้าโปรแกรม (ดู [[login-flow]]) |
| `use_barcode` | 1 | ใช้บาร์โค้ด |
| `get_last_price_type` | 0 | ไม่ดึงราคาขายล่าสุด/เฉลี่ย (ใช้ลำดับราคาปกติ) |
| `discount_step_round_off`, `calc_item_price_discount` | 0, 0 | ส่วนลดคิดจากยอดรวมรายการ ปัดเศษทุกขั้น |
| `cn_actual_cost`, `lot_manual_by_year` | 0, 0 | ค่าเริ่มต้นของล็อต |
| `show_branch_doc_only`, `disable_item_cost`, `auto_insert_time` | 0, 0, 0 | — |
