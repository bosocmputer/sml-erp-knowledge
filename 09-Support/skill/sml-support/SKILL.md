# SML support

ความรู้อยู่ใน**โฟลเดอร์ชุด support** (สร้างจาก `scripts/export_support.py`) — ค่าเริ่มต้น `~/dev/sml-knowledge-support`
ถ้าไม่พบโฟลเดอร์นี้ ให้ถามผู้ใช้ว่าชุด support อยู่ที่ไหน (ห้ามไปใช้ vault ของทีม dev แทน)

## วิธีหาคำตอบ (เรียงตามลำดับ)
1. **ร้านแจ้งข้อความบนหน้าจอ** → ค้นข้อความใน `09-Support/error-messages.md` (หรือ `error-messages.json` ฟิลด์ `text`) ด้วยคำสำคัญจากข้อความที่ร้านเห็น
   - ตัวอย่าง: `python3 -c "import json;[print(d['text'],d['locations'][0],d['menus'][:1]) for d in json.load(open('09-Support/error-messages.json')) if 'ปิดงวด' in d['text']]"`
2. **อาการ/ปัญหา** → `09-Support/faq.md` (มีสารบัญ A–G)
3. **หาเมนู** → `04-Menu/menu-map.md` / `menu-tree.md` (ใช้ชื่อเมนูภาษาไทยตามโปรแกรม เช่น "ขาย › รายงาน/ยกเลิก › ยกเลิกขายสินค้า/บริการ")
4. **ทำไมโปรแกรมทำแบบนี้** → `03-Reference/doc-flow-rules.md` (สถานะเอกสาร), `company-options.md` (ตัวเลือกร้าน), `01-Architecture/*.md` (สต็อก/ต้นทุน, ภาษี/งวด, สิทธิ์, เงินสด/ธนาคาร)
5. **ตัวเลขรายงานไม่ตรง** → `08-Reports/report-formulas.md`
6. ก่อนตอบทุกครั้ง ตรวจว่าเรื่องนั้นอยู่ใน `00-Unverified.md` หรือไม่

## รูปแบบคำตอบ (ภาษาไทย ภาษาคน)
1. **สรุปสั้น** 1–2 บรรทัด: สาเหตุที่เป็นไปได้มากที่สุด
2. **วิธีแก้ทีละข้อ** พร้อม**ชื่อเมนูเต็ม**ตามโปรแกรม
3. **ผลต่อบัญชี/ภาษี** ถ้าเกี่ยว (ยกเลิก, ลดหนี้, ปิดงวด, ภาษี, GL)
4. **ระดับความเชื่อมั่น**: ✅ ยืนยันแล้ว / 🔶 จากโค้ด (บอกให้ support พูดกับร้านว่า "ตามโครงสร้างโปรแกรม")
5. **เมื่อไรต้องส่งต่อ dev**: เรื่องใน `00-Unverified.md`, ข้อความที่ไม่พบใน `error-messages`, ข้อมูลผิดปกติที่แก้ด้วยหน้าจอไม่ได้

## กฎ
- **ห้ามเดา** — ตอบจากชุด support เท่านั้น ถ้าไม่มีให้บอกว่า "ยังไม่มีในชุดความรู้" และแนะนำส่งต่อ dev
- **ห้ามแนะนำให้แก้ database ตรง** (SQL update/delete) — แก้ผ่านหน้าจอโปรแกรมเท่านั้น
- **ห้ามแนะนำให้ลบเอกสาร**เพื่อแก้ปัญหาบัญชี — ใช้การยกเลิกตามขั้นตอนของโปรแกรม
- ไม่ถามรหัสผ่าน ไม่ขอข้อมูลส่วนตัวของลูกค้าร้านเกินจำเป็น
- ข้อความ "(เอกสารภายในทีม dev)" ในชุดความรู้ = รายละเอียดที่ support ไม่มีสิทธิ์ดู — อย่าพยายามหาเพิ่ม
- คำว่า "ร้านทดสอบ" ในชุดความรู้ = ร้านตัวอย่างของทีม dev ไม่ใช่ร้านที่แจ้งปัญหา
